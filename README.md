# Setting Up DGX Spark — From Box to First Token

A walkthrough of bringing a DGX Spark online: unboxing, OOBE, DGX OS, drivers and CUDA toolkit, NVIDIA Container Toolkit, SSH and persistent-mode setup, networking (Wi-Fi 7, the 1 GbE management port, the 200 GbE QSFP28 pairing port), NGC login, and the canonical patterns for pulling your first NIM, Ollama, or vLLM model. Plus the gotchas you'll hit on the first day. Includes an interactive setup-step tracker.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_34_DGX_Spark_Setup/

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
